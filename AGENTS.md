# AGENTS.md

A browser extension that brings danmaku (bullet comments) to any website.

## Tech
- Targets Chrome and Firefox.
- Written in TypeScript.
- Danmaku data is stored locally; there is no backend.

## Docs
- General documentation lives in `docs/`.

## Language
- Write documentation, code comments, and commit messages in English.

## Git
- Use Conventional Commits for commit messages.
